# 💰 Student Budget Tracker

A simple web app that helps students track income and expenses, see their balance at a glance, and understand where their money goes by category.

## Why I built this

- High school and college students face sudden financial independence without any formal training in money management.Solving 
- Existing corporate budgeting apps are too intimidating, ad-heavy, or complicated for a student's simple cash flow.
- I wanted to build a clean, minimalist utility tailored specifically to student categories (like textbooks, transit, and cheap eats) to lower the barrier to financial literacy.
- I wanted to challenge myself by moving away from passive classroom learning and building a real, functional product that addresses a community need.

## Features

- Add income and expense transactions with a description and amount
- Categorize expenses (Food, Transport, Textbooks, Rent, Entertainment, Other)
- See real-time balance, total income, and total expenses
- Visual breakdown of spending by category (pie chart)
- Delete transactions
- Data saved automatically in the browser (no login needed)

## Built with

- HTML, CSS, JavaScript
- Chart.js for the expense breakdown chart
- Browser localStorage for saving data

## What I learned
- I learned how to take a software concept from a raw idea, code it through structural design, and manage a live deployment using git version control.
- I mastered how to handle data flow and save user inputs locally using browser storage so information survives a page refresh.
- I learned how to implement responsive design, ensuring menus and data charts scale perfectly for students using the app on their phones.
- I discovered that writing clean code is only half the battle; building a successful product requires understanding user friction and prioritizing accessibility.

## What I'd add next

- Track the date of each transaction and filter by month
- Edit a transaction instead of only deleting it
- Export transaction history to a spreadsheet
